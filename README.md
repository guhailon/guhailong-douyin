### 语音包 31

31. 语音包（选音色 → 试听 → 合成并分享）。**不是真人声音克隆**：做法是本机 TTS
    （AVSpeechSynthesizer）+ 录音后变调（AVAudioEngine 变调/变速），内置 6 个变调音色
    （原声/女声/男声/萝莉/大叔/机器人）。真要像“语音包里对方那个人”需要对方音色的声音模型
    （类似 RVC），插件里实时跑不现实；也没有对方音色样本。等皇上发语音包样本后，
    再按样本的音调/共振峰调映射参数。直播里发语音目前只做运行期探针，不 hook、不注入、不发包。
    xuu 的 dylib 只当行为参考（选语音、语音包列表、试听、发送这条线），**没有反编译、没有复制
    它的代码、没有把它打进包里**；它的远程语音服务（要联网拉音色/可能要 UDID 验证）我们没有，
    也不绕过——我们的音色全部是本机生成的，不联网、不验证。

## 构建

- 构建走 guhailon 账号的 GitHub Actions macOS（跟分屏同一套路），仓库 `guhailon/guhailong-douyin`
  （私有，仅自用）。workflow 是 `source/.github/workflows/build.yml`（照抄分屏已验证的那套，
  不要用 fork 自带的 `huami1314/theos-action`，原作者仓库已 404）。
- 推代码就自动跑，跑完在 Actions 运行的 Artifacts 里下载
  `com.guhailong.douyin_1.0.0_iphoneos-arm64.deb`（rootless arm64）。
- 本地只做语法检查：`~/theos` 已装（含 iPhoneOS16.5.sdk），`make package` 能编过即可；
  **Linux 编出的 .deb 必须删掉、绝不能装**（Linux 编的自定义类会黑屏，分屏已证明；只认 macOS 编的包）。
- 验包老规矩：`dpkg-deb -I/-c`、包名 `com.guhailong.douyin`、版本 1.0.0、rootless arm64、
  大小和 SHA256 记下来。
